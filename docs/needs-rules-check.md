# Rules to check

Each line follows `RULING: <rule> | <what we did> | <why>`. The owner reconciles these in one sitting.
Status words in the "why" column: **Confirmed** (a source agrees), **Corrected** (a source disagreed and
the spec now follows it), **Unsourced** (the sources are silent; our ruling stands), **App** (card data
only the official app can settle).
